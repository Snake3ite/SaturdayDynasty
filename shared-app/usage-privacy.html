Usage & privacy

Updated September 17, 2026 — Build 236 reporting revision. This supplements the game's existing privacy information for accounts, billing and ads.

Basic game totals

Basic reporting is on by default for new players and players who have not made a reporting choice. Earlier reporting refusals remain off. Basic reports send event types, Android or browser platform, approximate event times and relevant product types: sessions, first reporting launches, new dynasties, completed games and seasons, guide and feature use, shop visits, checkout outcomes and ads actually displayed. They do not contain a persistent installation ID. A separate random ID for each event prevents retries from counting it twice; it is not reused for other events.

Optional ID tracking

ID tracking is off unless you enable it. It adds a random installation ID to future activity so we can measure unique and returning players. Earlier basic events are not assigned the ID when you enable this setting. Players who previously allowed reporting with a random ID keep their existing choice. The ID is hashed before storage. This linked data is pseudonymous, not completely anonymous.

Your controls

In Settings → Usage & privacy, you can switch off Share basic game totals to stop all usage reporting, or switch off Allow ID-based usage tracking while continuing to contribute basic totals. Declining does not change gameplay, purchases or access to features. Ad privacy choices are separate.

What stays out of usage reports

This feature does not send dynasty saves, player names, account emails, payment details or advertising identifiers. Basic requests still use ordinary internet connections: hosting providers may process IP addresses and keep operational logs. We do not store IP addresses as reporting identifiers or use fingerprinting to reconstruct an installation ID.

Purpose and service providers

Supabase receives and stores activity to help us understand and improve the game. Resend delivers aggregate daily reports to the developer. Emails do not contain device or event IDs. Usage reporting does not track you across other apps and is not used for personalized advertising. It is separate from Google Play, Stripe and AdMob provider records.

Storage and retention

Up to 500 events can wait on your device while offline. Events older than seven days are not accepted. Raw server events are removed after 35 days; aggregate totals are retained for long-term reporting. Report snapshots are retained for 90 days. For ID-enabled players, a hashed installation record is retained to distinguish first and returning activity.

Turning off ID tracking deletes the local installation ID and removes it from unsent events. Basic totals can continue. Turning off basic reporting clears the pending queue and stops future uploads. Neither setting retracts events already received or erases existing aggregate totals. Enabling ID tracking again creates a new ID. Clearing app/browser storage can also start a new reporting history. First reporting launches are not verified Google Play installs.
